# Security Policy

MoonFace is a research codebase; it places no orders and stores no credentials.
The only secrets it ever reads are optional, user-supplied environment variables
(e.g. a Telegram bot token for `moonface-feed`).

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/nqh98/moonface/security/advisories/new)
with a description and reproduction steps. You can expect an acknowledgement within
7 days.

Never paste real API keys or tokens into issues, PRs, or logs.
